# examples

## 示例 1：让步接收判断

问题：`AX-20250518-01 批次 42 件硬度不合格能否让步接收？`

1. 检索 SPC/检验台账 → 得到实测范围 45.5–47.4 HRC，低于 48；
2. 检索《SP-INSP-AX》→ 得到规格限；
3. 检索《QP-INC-03》→ 4.3 要求客户书面同意且经质量经理批准；
4. 反证检查：未发现该客户历史书面让步授权；
5. 结论：默认不可让步，走返工+复检；若仍需让步须客户书面批准并留痕。

## 示例 2：根因归因

问题：`该批硬度不合格是否与 3 号热处理炉温漂相关？`

证据步：SPC 控制图越限 → 维保记录热电偶校准超期 → 工艺规程校准要求 → 设备关联。
输出应包含证据链 JSON、Mermaid 决策图和来源引用。
