# evidence-decision

本技能适用于需要“基于证据给出决策”的问题，例如不合格品处置、让步接收判断、
质量异常根因分析、跨文档多跳归因。禁止在没有证据支撑时直接下结论。

## 工作流程

1. **路由问题**：判断问题类型（根因/处置/数值/标准条款/图文），选择优先知识库
   （标准规程库 / 台账与记录库 / 图片证据库）与工具。
2. **拆解问题**：长问题按语义拆为最小子问题，逐项取证。
3. **检索证据**：
   - 条款/规程 → `search-knowledge-base`（标准规程库）；
   - 数值/批次/设备 → 台账摘要与 `analyze-text-file`；
   - 图表/缺陷图 → `analyze-image` 提取图片事实；
   - 实体关系 → 图谱检索工具。
4. **构建证据链**：每条断言至少绑定 1 条证据（evidence_id、来源文件、原文片段、
   支持/反证角色）；输出 JSON 化断言与证据清单。
5. **反证检查**：主动搜索可能推翻结论的证据；若存在反证，应说明边界或修正结论。
6. **校验引用**：调用覆盖检查，确保结论断言可溯源、无孤儿引用。
7. **输出**：Markdown 答案中使用引用标记（如 `[[S1]]`），并给出 Mermaid
   `flowchart LR` 决策图；证据不足时明确声明并给出缺口。

## 参数

参考 `config/schema.yaml`：

- `top_k`：单个检索源最大返回条数，默认 5；
- `require_citations`：是否强制每条结论带引用，默认 true。

## 边界与错误处理

- 检索不到证据时，不要编造来源；返回“证据不足”并列出待补充资料。
- 当检索工具报错时，重试一次后仍失败则改用备用知识库/文本解析工具。
- 证据链未通过覆盖检查时，不得输出“完成”结论。
- 适用于合成演示数据与公开标准摘要；真实标准请以授权原文为准。
