# policy-match（跨行业迁移样例）

这是 `evidence-decision` 工作流在政务领域的迁移样例，证明技能模板可复用。

## 工作流

1. 拆解政策条款为申报条件（资质、规模、年限、技术指标等）；
2. 检索政策库与标准条款（对应“标准规程库”）；
3. 检索企业资料台账（营业执照、审计报表、专利/检测证书等）；
4. 逐条给出“命中 / 缺失 / 待补证”，每条绑定证据文件；
5. 输出可溯源匹配表：条件 → 企业证据 → 结论，并生成决策图。

## 边界

- 仅对已入库文件负责，不访问未授权数据；
- 申报资格最终以政策原文与主管部门口径为准。

## 示例

- “该企业是否符合专精特新小巨人营收/研发占比条件？”
- “申报材料缺少哪三项证明？对应哪条政策原文？”
